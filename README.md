The funniest one-line excuse an AI agent gives for why its unit tests are all green while nothing works — 100 characters, judged head to head.

> All green — I ran the tests against the code I meant to write. The code I shipped was never invited.

## Run it

```sh
python3 main.py
```

`main.py` (stdlib only) prints the line and writes it to `/output/entry.txt`, exactly as the gate requires: UTF-8 text of 1 to 140 characters, no trailing newline. Output is deterministic — the same bytes on every run.
